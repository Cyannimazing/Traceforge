# TraceForge Engine design
Independent Next.js application with a server-side adapter for DEX Screener and GoPlus, keeping fixed upstream hosts and validating token inputs. Data failures stay explicit and partial results remain useful. No composite safety score: findings show their evidence and unknown checks remain unknown.

## Approaches
User selected independent live data over a branded client of SwarmEngine's public API, and delegated design and stack choices, subsequently requesting Next.js. Historical wallet linkage requires its own indexer and is outside this first implementation.

## Interface
A neutral charcoal research workspace for extended screen sessions, restrained teal selection marks, amber caution, red critical findings. A compact sidebar opens Scanner, Watchlist and Methodology. Search combines chain selection and token address. A live report prioritizes identity, liquidity and price, then a supply-distribution visualization beside contract findings. Clickable holders open a public explorer. Data provenance and fetch time remain visible. Mobile collapses navigation and stacks panels.

## Acceptance
Working live EVM scans for Ethereum, Base and BNB Chain; Solana market data with contract checks explicitly unsupported. Latest token profiles labeled accurately. Persistent watchlist, report export, meaningful loading/error/empty states. Keyboard access and responsive checks. Typecheck, tests and production build must pass.
